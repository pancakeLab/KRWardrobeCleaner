# 히메짱 옷장 정리기 (KRWardrobeCleaner) — 배포 저장소

FF14 한국 서버용 Dalamud 플러그인 **히메짱 옷장 정리기**의 릴리스 파일(`KRWardrobeCleaner.zip`)을 배포하는 저장소입니다.
소스 코드는 포함되어 있지 않습니다(비공개 저장소에서 관리).

## 설치

Dalamud 설정 → 실험적 기능 → **사용자 정의 플러그인 저장소**에 아래 주소를 추가하세요.
히메짱 WHM(Rotation Solver Reborn 포크)과 **같은 주소**이므로, 이미 등록했다면 추가로 할 일이 없습니다.

```
https://raw.githubusercontent.com/pancakeLab/Himechan_addon/himechan/pluginmaster.json
```

등록 후 플러그인 설치 창에서 "히메짱 옷장 정리기"를 검색해 설치합니다.

- Dalamud API 15 / .NET 10 / x64
- 각 릴리스의 `SHA256SUMS.txt`로 파일 무결성을 확인할 수 있습니다.

## 이전 안내

예전 저장소 주소(`.../yaaung-ai/KRWardrobeCleaner/main/repo.json`)는 더 이상 사용되지 않습니다.
Dalamud에 그 주소가 남아 있으면 삭제한 뒤, 위 주소로 플러그인을 다시 설치하세요.
